# SplitMate

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
모임·여행 정산을 초간단하게 — 더치페이 계산기에 리워드 광고로 '1/N 영수증' PDF 출력 잠금 해제

## Problem
친구·동료와 식사·여행 후 복잡한 더치페이 계산을 카카오톡 계산기나 엑셀로 수동 처리하며 시간 낭비. 특히 개별 아이템 분담·비균등 분할이 불편함

## Target Users
모임·여행을 자주 즐기는 20-35대 사회초년생·직장인, 동호회·MT 총무 역할 담당자

## Core Features
1. 항목별 금액 입력 + 인원 지정 (예: A는 스테이크, BC는 파스타)
2. 비균등 분할 (비율·고정금액·제외 등) 지원
3. 토스 송금 딥링크 연동 — 계산 후 1탭으로 정산 요청
4. 리워드 광고 시청 후 정산 내역 이미지/텍스트 공유 기능 잠금 해제
5. 최근 3개 정산 내역 localStorage 저장
6. 배너 광고: 결과 화면 하단 자연 배치

## Monetization
- Model: ads
- Estimated MRR: 5100000
- Reasoning: DAU 4,000 기준. 리워드 광고(공유 기능 게이팅, 전환율 20%): 4,000×0.2×30×4/1000×1350×0.85 = 약 275만 원. 배너(2 노출): 4,000×2×30×1/1000×1350×0.85 = 약 275만 원. 합산 약 550만 원 → 15% 수수료 후 순수익 약 467만 원. 주말·휴일 트래픽 피크로 실 수익 향상 기대.
